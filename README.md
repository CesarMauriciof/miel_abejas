## 📌 Descripción del proyecto

MielAbejas es una landing page y sitio web comercial centrado en la marca de miel de la empresa. Su objetivo es presentar la historia, los productos, el proceso artesanal y facilitar la interacci[...]

Este proyecto refleja mi capacidad para:

- Diseñar interfaces modernas y atractivas
- Construir aplicaciones SPA con Angular
- Implementar navegación con rutas y componentes estructurados
- Crear layouts responsivos para distintos dispositivos
- Trabajar con estilos avanzados en SCSS
- Preparar una base para integración con Firebase y servicios web

## 🚀 Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Node.js 18 o superior
- npm
- Angular CLI

```bash
npm install -g @angular/cli
```

---

## ⚙️ Instalación

Clona el repositorio:

```bash
git clone https://github.com/CesarMauriciof/miel_abejas.git
cd miel_abejas
```

Instala las dependencias:

```bash
npm install
```

---

## ▶️ Ejecución

Inicia la aplicación en modo desarrollo:

```bash
npm start
```

O bien:

```bash
ng serve
```

Luego abre tu navegador en:

```text
http://localhost:4200/
```

---

## 📦 Scripts disponibles

```bash
npm start
```
Ejecuta el proyecto en modo desarrollo.

```bash
npm run build
```
Genera la versión de producción en la carpeta `dist/`.

```bash
npm run watch
```
Compila la aplicación y observa cambios en tiempo real.

```bash
npm test
```
Ejecuta las pruebas unitarias con Karma.
